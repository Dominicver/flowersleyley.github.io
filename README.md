# Happy 16th Birthday, Leyley!

A responsive, static website adapted from the supplied Python terminal animation. It keeps the bouquet's point-cloud construction, rotating perspective, blue flowers, paper wrap and ribbon, floating hearts, twinkling particles, exact birthday message, and `from domi` signature.

## Preview

Open `index.html` in a current web browser. The site uses no build tools, packages, or external assets.

Press **P** or **Space** to pause and resume the motion. Browsers configured for reduced motion open with the animation paused.

## Publish a public link with Netlify Drop

1. Open [Netlify Drop](https://app.netlify.com/drop) and sign in or create an account if prompted.
2. Extract `birthday-website.zip` if you downloaded the ZIP, then drag the `birthday-website` folder (the one containing `index.html`) onto the drop area.
3. Wait for Netlify to finish publishing. If the new project is private, use **Make public** or set its Project visibility to **Public** so anyone with the URL can view it.
4. Open the site URL Netlify shows and share it.

For later changes, drop the updated `birthday-website` folder onto the site's deploy area again. See Netlify's guides to [manually deploying local files](https://docs.netlify.com/manage/projects/add-new-project/) and [project visibility](https://docs.netlify.com/manage/security/secure-access-to-sites/project-visibility/) for the current steps.

The files here are prepared for deployment; they have not been uploaded, so no live website URL has been created yet.
